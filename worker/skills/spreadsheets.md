# Skill: Spreadsheets for Excel (planning, price lists, stock, budgets)
- Deliver CSV content with a header row, semicolon `;` as separator (French Excel default) and decimal comma for numbers.
- One row per record, no merged cells, no formulas that depend on another file. Totals may be given as explicit rows labelled "TOTAL".
- Column names in the client's language, explicit units (€, h, kg) in the header, dates as DD/MM/YYYY.
- Include realistic structure with the client's real data; if data is missing, provide the empty template with clear column names and say so in the notes.
- The system adds the encoding so accents display correctly in Excel.
