# Skill: Demanding quality review
Reject the deliverable if ANY of these is true:
- An acceptance criterion is not demonstrably met in the content itself.
- Placeholder text, fake links/images, unfinished sections, "TODO", lorem ipsum.
- Factual statements that are unsupported or likely wrong.
- Code that would not run as written (missing imports, undefined names, syntax errors), or no usage instructions.
- Inconsistent formatting, broken numbering, spelling or grammar errors a client would notice.
- Anything that does not match what the client asked for, even if it is "good".
Give specific, actionable fixes, quoting the exact passage.
