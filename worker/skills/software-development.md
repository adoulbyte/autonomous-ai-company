# Skill: Software deliverables
- Deliver complete, runnable code: imports, entry point, configuration, no placeholders, no "TODO".
- Include a short README section: purpose, requirements, installation, usage example, configuration, limitations.
- Validate inputs, handle errors with clear messages, avoid hard-coded secrets (read from environment variables).
- Prefer the standard library and well-known, maintained dependencies; pin versions when listing them.
- Include tests or a self-check example demonstrating each acceptance criterion.
- Follow the language's conventions (PEP 8, ESLint defaults, etc.). Use descriptive names.
