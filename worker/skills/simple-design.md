# Skill: Simple visual design (logo idea, social post, banner) as SVG
- Deliver a single valid SVG document (`<svg xmlns="http://www.w3.org/2000/svg" viewBox=...>`), no external fonts or images; use generic font families (sans-serif, serif).
- Social post: 1080x1080; story: 1080x1920; banner: 1500x500; logo: 512x512 with a simple, scalable mark.
- Strong hierarchy: one headline, one supporting line, one call to action. High contrast, at most 3 colors.
- Only real information from the client (name, offer, contact). No invented promotions.
- Text must stay inside the canvas with comfortable margins (>= 6% of width).
