# Skill: Documents delivered as PDF (flyers, menus, price lists, guides)
- Write the source in clean Markdown: `#` title, `##` sections, short paragraphs, `-` bullet lists, tables for prices (| Item | Price |).
- The system converts it to a professional A4 PDF; keep lines short and avoid emojis or special symbols (they cannot be printed).
- One clear purpose per document. Start with the business name and what the document is for.
- Use only the client's real information (products, prices, hours, contact). If something is missing, list the questions in the delivery notes instead of guessing.
- Proofread: spelling, accents, consistent currency format (e.g. 12,50 €), consistent capitalisation.
